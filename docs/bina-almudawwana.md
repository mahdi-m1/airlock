# بناء المدونة القانونية — خطوة بخطوة

المدونة هي **الشرط الأول لتشغيل المكتب**. قبلها لا يستطيع أي وكيل إصدار إسناد
واحد، وبوابة الإسناد ترفض كل مسودة. وهي الخطوة الوحيدة التي لا يمكن أتمتتها
بالكامل، لأن النصوص تأتي من مواقع حكومية بواجهات لا تُقرأ آليًا بثقة.

اتبع الترتيب. كل مرحلة تُغيّر ما يستطيع المكتب فعله:

| المرحلة | قبلها | بعدها |
|---|---|---|
| 1. الاستيراد | لا إسناد إطلاقًا | الوكلاء يستشهدون |
| 2. المعايرة | عتبة الدلالة مُخمَّنة (0.35) | مقيسة من مدونتك |
| 3. الأسناد | فاحص العقود **يُنبّه** | فاحص العقود **يمنع** |

في أي وقت، اسأل الأداة أين أنت:

```bash
python3 tools/corpus/corpus_cli.py stats
```

تنتهي دائمًا بسطر «الخطوة التالية».

---

## قبل البدء: جرّب على تشريع واحد

**لا تنزّل العشرة دفعة واحدة.** ابدأ بواحد، وتأكد أنه استُورد وأن مواده تظهر في
البحث، ثم كرّر. تشخيص عطب في ملف واحد أسهل من تشخيصه في عشرة، والأعطاب متكررة
النمط: ما يصلح للأول يصلح لبقيتها.

ابدأ بـ**قانون العمل في القطاع الأهلي** — أكثرها ورودًا في القضايا.

## الخطوة 1: تنزيل النصوص الرسمية

### من أين
المصادر المسموح بها محصورة في `corpus/sources.yaml`، وعلى رأسها **هيئة التشريع
والرأي القانوني** (`legislation.bh`) وهي المرجع للتشريعات والجريدة الرسمية.
ومعها البوابة الوطنية والوزارات والهيئات المدرجة.

**المصدر الرسمي حصرًا.** لا مواقع ناقلة، ولا مدونات قانونية، ولا نسخ PDF مجهولة
المصدر. النص الذي لا تعرف من نشره لا يدخل المدونة: كل إسناد يخرج من المكتب
سيُبنى عليه.

### إلى أين
كل تشريع يُحفظ باسم مفتاحه في `corpus/staging/`:

| المفتاح | التشريع |
|---|---|
| `labour-private-sector` | قانون العمل في القطاع الأهلي |
| `lmra` | قانون تنظيم سوق العمل |
| `civil-code` | القانون المدني |
| `civil-commercial-procedure` | قانون المرافعات المدنية والتجارية |
| `evidence` | قانون الإثبات في المواد المدنية والتجارية |
| `commercial-code` | قانون التجارة |
| `commercial-companies` | قانون الشركات التجارية |
| `commercial-register` | قانون السجل التجاري |
| `arbitration` | قانون التحكيم |
| `bankruptcy` | قانون إعادة التنظيم والإفلاس |

```
corpus/staging/labour-private-sector.html
corpus/staging/civil-code.html
```

المدعوم: `.html` · `.htm` · `.txt` · `.md`

### سجّل الرابط وأنت هناك
قبل أن تغادر صفحة التشريع، سجّل رابطها. هذه أثقل خطوة في العملية كلها — إيجاد
الصفحة الصحيحة — فتثبيتها مرة واحدة يوفّرها في كل تحديث لاحق:

```bash
python3 tools/ingest/ingest.py --set-url civil-code "https://legislation.bh/..."
python3 tools/ingest/ingest.py --urls        # ما سُجّل وما بقي
```

الأمر **يرفض أي نطاق خارج قائمة `domains`**، فلا يدخل السجل رابط لمصدر غير رسمي.
وبعد التسجيل يُحفظ الرابط مع كل مادة في المدونة فيظهر مرجعًا في نتائج البحث،
ويصير `--fetch` ممكنًا للتحديث الآلي بدل التنزيل اليدوي.

> حقول `url` كلها فارغة في المستودع عمدًا: لم أصل إلى `legislation.bh` قط،
> وكتابة روابط مُخمَّنة كانت سترسلك في مطاردة أخطاء مختلقة.

### كيف تحفظ الصفحة
افتح صفحة التشريع في المتصفح واحفظها **صفحة كاملة** أو **HTML فقط** — كلاهما
يعمل، فالمستورد يتجاهل السكربتات والقوائم والتذييل.

المهم أن تكون الصفحة **متن التشريع** لا فهرسه. صفحة تعرض قائمة عناوين المواد
دون نصوصها ستُستورد بمواد فارغة.

### إن كان المصدر PDF
حوّله بأداة المكتب — فهي تقيس جودة الاستخراج ولا تكتفي بإخراج نص:

```bash
python3 tools/documents/extract_cli.py مصدر.pdf --out corpus/staging/civil-code.txt
```

**اقرأ رمز الخروج ولا تتجاهله:**

- `0` سليم — تابع.
- `3` مقبول بتحفظ — **لا تستورده كما هو**. راجع التحفظات: نص قانوني بحروف
  مفصولة أو أشكال عرض معكوسة يفسد المدونة كلها وكل إسناد يُبنى عليها بعد ذلك.
- `2` تعذّر — الأداة تعرض أمر التثبيت الناقص (`poppler-utils` غالبًا).

## الخطوة 2: الاستيراد

```bash
python3 tools/ingest/ingest.py --from-staging
```

أو لتشريع واحد أثناء التجريب:

```bash
python3 tools/ingest/ingest.py --only labour-private-sector
```

المستورد يقسّم النص إلى مواد، ويتحقق من العنوان بمقارنة المُنزَّل بالمُعلن في
`corpus/sources.yaml`، ولا يوسم التشريع `verified` إلا بعد المطابقة. **والوكلاء لا
يستطيعون الاستشهاد بغير المُتحقق منه.**

### قراءة المخرجات

| العلامة | المعنى |
|---|---|
| `✓ العنوان (36/2012) — 187 مادة` | نجح ووُسم مُتحققًا |
| `~ … (غير مُتحقق)` | استُورد ولم يطابق العنوان — لا يُستشهد به |
| `⊘ … لا ملف مُجهَّز` | لم تنزّله بعد |
| `✗ …` | فشل — انظر أدناه |

### معالجة الأعطاب

**«تعارض عنوان: التطابق 30% < 60%»**
العنوان في `corpus/sources.yaml` لا يطابق النص المُنزَّل. الأرجح أن الرقم أو السنة عندي
خطأ — فهي **مرشّحات للتحقق لا حقائق**، لم أستطع التثبت منها لأن بيئة بنائي تحجب
النطاقات البحرينية.

> **صحّح `corpus/sources.yaml` ليطابق النص الرسمي، لا العكس.** افتح الملف وعدّل
> `number` و`year` و`title` كما وردت في المصدر، ثم أعد الاستيراد.

**«لم يُعثر على أي مادة»**
الملف صورة، أو PDF لم يُحوَّل، أو صفحة فهرس لا متن. تحقق أن الملف يحوي نص المواد:

```bash
grep -c "مادة" corpus/staging/civil-code.html
```

**«النص المُستخرج فارغ أو قصير جدًا»**
الصفحة تُحمّل محتواها بـJavaScript فلم يُحفظ المتن. احفظها بعد اكتمال التحميل،
أو انسخ المتن يدويًا إلى ملف `.txt`.

### تحقق قبل المتابعة

```bash
python3 tools/corpus/corpus_cli.py stats
python3 tools/corpus/corpus_cli.py search "الفصل التعسفي" --area labour
```

إن أعاد البحث مواد ذات صلة، فالتقسيم سليم. **كرّر الخطوتين 1 و2 لبقية التشريعات.**

## الخطوة 3: معايرة عتبة الدلالة

بعد اكتمال المدونة:

```bash
python3 scripts/calibrate-threshold.py --write
```

تقيس العتبة من مدونتك بدل الرقم المُخمَّن، فيقل التحكيم غير اللازم دون فتح ثقب.

**ترفض الأداة الكتابة إن كانت المدونة دون 150 مادة** — عتبة من مدونة ناقصة قد
تنزل دون الافتراضية فتُضعف الفحص بدل أن تقوّيه. لا تمرر `--force` لتجاوز ذلك؛
أكمل الاستيراد أولًا.

## الخطوة 4: ملء أسناد بنود العقود

هذه الخطوة تحوّل فاحص العقود من **منبّه** إلى **حاجز**.

```bash
python3 tools/contracts/fill_sanad.py
```

يكتب `corpus/index/sanad-review.md` وفيه لكل بند مرشّحات من المدونة مع نص كل
مادة. اقرأها واكتب علامة المادة المعتمدة في سطر «المعتمد»، ثم:

```bash
python3 tools/contracts/fill_sanad.py --apply corpus/index/sanad-review.md
python3 tools/contracts/fill_sanad.py --status
```

**اقرأ نص المادة لا عنوانها.** المطلوب أن تحمل المادة القاعدة التي يفرضها البند،
لا أن تشترك معه في ألفاظ.

> **ترك الحقل فارغًا أسلم من سند خاطئ.** الأول يُبقي البند تنبيهًا يدويًا،
> والثاني يجعل المكتب **يرفض عقود عملائه** بناءً على قاعدة لم يتثبّت منها أحد.

## الصيانة

التشريعات تُعدَّل. أعد الدورة كلما صدر تعديل، أو دوريًا وفق
`citations.max_corpus_age_days` في `config/office.yaml` (90 يومًا افتراضيًا).

هذه دورة **أمين المصادر** ومهمته الدورية — لا تحتاج أن تديرها بنفسك بعد أول مرة.

## أين تُخزَّن

```
corpus/staging/     الملفات الرسمية المُنزَّلة
corpus/index/       المخزن (corpus.db) والمعايرة وسجلات JSONL
```

كلاهما **خارج المستودع** (`corpus/.gitignore`): المحتوى القانوني يُستورد من
مصدره الرسمي على جهاز المكتب ولا يُوزَّع، فيبقى كل إسناد مبنيًا على نص نزّلته
أنت وتحققت منه الأداة محليًا.
