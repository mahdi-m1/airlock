# مكتب استشارات قانوني آلي — مملكة البحرين

مكتب استشارات قانوني يعمل **بلا موظف بشري**، مبني على منصة
[Paperclip](https://github.com/paperclipai/paperclip) مفتوحة المصدر.
يستقبل القضايا ويحللها ويكتب المذكرات والمرافعات وفق القانون البحريني،
بمخرجات تبقى على الجهاز، وبمسار إسناد قابل للتحقق.

**التغطية:** مدني · تجاري · عمالي   **اللغة:** العربية فقط   **المنصة:** Linux

---

## الفكرة في ثلاث نقاط

**1. الاستقرار يأتي من المحرّك لا من التعليمات.**
القضية تسير في خط معالجة بعشر مراحل مع `enforceTransitions`. الانتقالات المسموحة
معرّفة صراحة، فلا يستطيع وكيل تخطي البحث إلى الصياغة، ولا تسليم مسودة لم تمر
بتدقيق الإسناد ثم المراجعة القانونية. مرحلتا المراجعة معتمِدهما **وكيل** لا بشر.

**2. لا إسناد بلا سند — على طبقتين.**
كل إشارة قانونية تحمل علامة آلية (`⟦BH:law:36/2012:م111⟧`).

- **الوجود:** تُحل العلامة إلى مادة موجودة فعلًا في مدونة محلية مستوردة من
  المصادر الرسمية. حتمي بالكامل — لا نموذج يحكم عليه.
- **الدلالة:** هل تقول المادة ما نُسب إليها؟ هنا يُرفض قطعًا المقدار المغلوط
  («خمسة وأربعين يومًا» منسوبة إلى مادة تقول «ثلاثين») وادعاءُ الجواز في مادة
  حاظرة. وما لا يُقاس يُحال إلى **ورقة تحكيم مهيكلة** يحسمها مدقق الإسناد بندًا
  بندًا، بنقل العبارة الحاملة من نص المادة — لا بانطباع عام.

الطبقة الثانية تعالج العطب الوحيد الذي يعبر فحص الوجود: أن يكون النص موجودًا
وصحيح الرقم، والحجة المبنية عليه مع ذلك لا يحملها. ولأن التحكيم لا يشمل إلا
البنود الملتبسة، تبقى كلفته بقدر الشك الفعلي لا بقدر طول الوثيقة.

**3. العزل مفروض تقنيًا لا موعود به.**
وكلاء القضايا يعملون داخل `bwrap` بمجال شبكي خاص، وقائمة سماحهم لا تحوي إلا واجهة
النموذج. **لا يستطيعون** بلوغ أي موقع. أمين المصادر وحده يبلغ النطاقات الرسمية،
وهو في مشروع منفصل لا يرى أي بيانات قضايا.

| | |
|---|---|

## التثبيت

```bash
./scripts/install.sh          # يفحص المتطلبات ويرشدك للخطوات
```

يتطلب: Linux، `bubblewrap`، Python ≥ 3.10 مع PyYAML وsqlite3/FTS5، Node.

ثم بالترتيب:

```bash
# 1) تحصين البيئة والتحقق منه
set -a; . ./config/env.local; set +a      # ضع ANTHROPIC_API_KEY أولًا
./scripts/verify-isolation.sh

# 2) تشغيل Paperclip واستيراد المكتب
npx paperclipai onboard
npx paperclipai company import ./maktab --dry-run
npx paperclipai company import ./maktab --target new \
    --new-company-name "مكتب الاستشارات القانونية" --yes
./scripts/verify-isolation.sh             # onboard يعيد تفعيل التليمتري — أعد الفحص

# 3) تهيئة الخط والعزل والسقوف
export PAPERCLIP_API_URL=http://127.0.0.1:3100
export PAPERCLIP_API_KEY=<token>
python3 scripts/provision.py --company-id <uuid>

# 4) بناء المدونة القانونية — المكتب لا يعمل بدونها
python3 scripts/build-corpus.py --plan    # ماذا سيفعل قبل أن يفعله
python3 scripts/build-corpus.py           # ينزّل ويستورد ويعايِر، ويقول ما بقي
python3 tools/corpus/corpus_cli.py stats
```

> `paperclipai company import` يأخذ المسار **موضعيًا** لا بـ`--from`،
> خلافًا لما في توثيق Paperclip.

## بناء المدونة القانونية

هذه أهم خطوة: **المكتب لا يستطيع إصدار أي إسناد قبلها**، والاستيراد يُشغَّل على
جهازك لأن النصوص تأتي من المصادر البحرينية الرسمية.

📘 **الدليل الكامل خطوة بخطوة: [docs/bina-almudawwana.md](docs/bina-almudawwana.md)**
— من أين تنزّل، وكيف تسمّي الملفات، وكيف تقرأ كل رسالة خطأ وتعالجها.

وفي أي وقت، `corpus_cli.py stats` ينتهي بسطر «الخطوة التالية» يقول أين أنت.

```bash
python3 scripts/build-corpus.py
```

يفحص سجل المصادر، وينزّل كل تشريع له رابط مسجَّل — من النطاقات الرسمية وحدها،
وكل تحويلة تُفحص على حدة — ويحوّل PDF وWord إلى نص، ويستورد ويتحقق، ويعايِر عتبة
الدلالة، ثم يطبع أمرًا جاهزًا لكل تشريع بقي.

**لا يخترع رابطًا ولا رقم جريدة ولا سطرًا من نص قانوني.** فالتشريع الذي لا رابط
له يبقى مُعلنًا في قائمة «ما بقي عليك» بدل أن يدخل المدونة بمصدر مُخمَّن.

### الروابط الناقصة: استكشفها من الفهرس الرسمي

المكتبة الإلكترونية لهيئة التشريع والرأي القانوني
([www.lloc.gov.bh/ElectronicLibrary](https://www.lloc.gov.bh/ElectronicLibrary))
تسرد التشريعات وتربط إلى نصوصها، وهي مسجّلة في `corpus/sources.yaml` تحت
`catalogs`:

```bash
python3 scripts/build-corpus.py --discover               # رشّح واعرض
python3 scripts/build-corpus.py --discover --write-urls  # وسجّل القاطع منها
```

يقرأ كل رابط ونصه من الفهرس، ويطابقه بالتشريعات التي لا رابط لها: تغطية العنوان
(بالتجذيع، فتُطابق الصيغ المصرّفة)، ورقم القانون وسنته (بالأرقام العربية
والهندية معًا، ورقم قائم بذاته لا جزءًا من رقم أطول)، ونوع التشريع. ويعرض سبب
كل ترشيح بدل رقم مجرّد.

وحين يضع الفهرس العنوان في الصف والرابطُ كلمةٌ واحدة («تحميل»، «PDF» — نمط
شائع في فهارس الملفات)، يطابق من **سياق الرابط**: أضيق كتلة تحيط به.

**المطابقة على نص الرابط لا على متن التشريع** — فقد يحمل الفهرس عنوانًا مختصرًا
أو عنوان مرسوم تعديل. لذلك `--write-urls` لا يسجّل إلا الترجيح القاطع (★:
تغطية عنوان ≥ 60% **و** الرقم والسنة معًا **و** ترجيح ≥ 0.90 **و** المطابقة من
نص الرابط نفسه لا من سياقه)، ويبقى وراءه حاجزان: المستورد يقارن العنوان بمتن
النص المُنزَّل، والتوثيق يظل ناقصًا فلا يُستشهد بالتشريع حتى تُسجَّل الجريدة.

الفهارس تقدّم أكثر تشريعاتها PDF، فالسكربت ينبّهك في مرحلة الفحص — قبل التنزيل —
إن نقصت خلفية قراءتها (`poppler-utils`، و`tesseract-ocr-ara` للمسح الضوئي).

سجّل التوثيق مرة واحدة وأنت تتصفّح:

```bash
python3 tools/ingest/ingest.py --set-provenance civil-code \
    --url "https://…" --gazette <العدد> --date YYYY-MM-DD
```

وما تعذّر تنزيله آليًا، نزّله يدويًا إلى `corpus/staging/<key>.html` (أو `.pdf`
أو `.docx` — تُحوَّل تلقائيًا) ثم أعد تشغيل السكربت.

الاستيراد **يتحقق من العنوان** بمقارنة النص المُنزَّل بالمُعلن في
`corpus/sources.yaml`، ولا يوسم التشريع `verified` إلا بعد المطابقة. والوكلاء لا
يستطيعون الاستشهاد بغير المُتحقق منه.

### التحقق من هوية التشريع

المستورد يقرأ **صيغة الإصدار** من متن النص المُنزَّل («قانون رقم (36) لسنة 2012»)
ويقابلها بالمسجَّل في `sources.yaml`. رقم أو سنة خاطئة تمر من فحص العنوان بلا
أثر — ثم تدخل **كل علامة استشهاد** تُولَّد من هذا التشريع: المادة صحيحة ونصها
صحيح، والقانون المنسوبة إليه غيره. ولا بوابة بعدها تلتقط ذلك، لأن كل شيء في
المدونة متسق مع نفسه. فعند الاختلاف يُرفض الاستيراد وتُعلَن الصيغة التي وُجدت
في النص.

> ⚠️ أرقام التشريعات وسنواتها في `corpus/sources.yaml` **مرشّحات للتحقق لا حقائق
> مثبتة** — لم يُتحقق منها آليًا لأن بيئة البناء تحجب النطاقات البحرينية. عند
> تعارض العنوان **صحّح السجل ليطابق النص الرسمي، لا العكس**.
> ولا يحوي هذا المستودع أي نص قانوني مكتوب يدويًا، عمدًا.

### التوثيق شرط في الاستشهاد

**الجريدة الرسمية هي المرجع النهائي الملزم**: القانون لا ينفذ إلا بالنشر فيها.
فلا يُوسم تشريع قابلًا للاستشهاد حتى يُعرف رابط مصدره ورقم عدد الجريدة وتاريخه:

```bash
python3 tools/ingest/ingest.py --set-provenance civil-code \
    --url "https://lloc.gov.bh/…" --gazette 2501 --date 2001-09-06
python3 tools/ingest/ingest.py --urls        # ما وُثّق وما بقي
```

النص بلا توثيق **يُستورد ويُخزَّن ولا يُستشهد به** — فلا يبني عليه وكيل مذكرة
ولا يُرفض به عقد عميل. يُضبط بـ`require_gazette_provenance` في
`config/office.yaml` (مفعّل افتراضيًا).

وبعد التوثيق يظهر مرجع الجريدة في كل نتيجة بحث وكل عرض مادة، جاهزًا للنقل.

### التعديلات

الاستشهاد بمادة عُدّلت — بنصها الأصلي — **خطأ لا تلتقطه أي بوابة**: المادة
موجودة، ورقمها صحيح، ونصها مطابق لما استُورد. لكن المحكمة تطبّق النص النافذ.

لذلك يحمل كل تشريع في `sources.yaml` قائمة `amendments` وعلم `consolidated`،
وعند نص أصلي له تعديلات يظهر تنبيه في كل نتيجة بحث وعرض مادة وتقرير بوابة.

**المصادر الرسمية** في `corpus/sources.yaml → domains` — 26 نطاقًا تشمل هيئة
التشريع (`lloc.gov.bh`)، ووزارة الشؤون القانونية (`mola.gov.bh`)، والجريدة
الرسمية (`mia.gov.bh`)، والنيابة العامة، ومجلس النواب.
إن تعذّر الوصول فالحجب على `.gov.bh` كثيرًا ما يكون جغرافيًا ويحلّه VPN
بموقع خليجي، أو استعمل تطبيق «تشريعات البحرين» الرسمي.

مصادر PDF تُحوَّل أولًا:
```bash
pdftotext -enc UTF-8 -layout ملف.pdf corpus/staging/<key>.txt
```

### معايرة عتبة الدلالة

عتبة التدقيق الدلالي **تُقاس من المدونة لا تُخمَّن**، و`min_semantic_overlap`
في `config/office.yaml` قيمته `auto` فتقرؤها البوابة من المعايرة:

```bash
python3 scripts/calibrate-threshold.py            # عرض التوصية
python3 scripts/calibrate-threshold.py --write    # اعتمادها
```

يبني السكربت أزواجًا **موجبة** (ادعاء مقتطع من المادة نفسها، يحاكي صياغة محامٍ
لا نسخًا) و**سالبة** (الادعاء ذاته منسوبًا لمادة أخرى، مرجّحة للمجاورة في نفس
التشريع لأنها الغلط الواقعي)، ثم يضع العتبة عند أعلى نقطة يبقى فيها فوات
الإسناد المغلوط ≤ 5%.

الأثر: العتبة **ترتفع من تلقاء نفسها** كلما كبرت المدونة، فيقل التحكيم غير
اللازم دون أن يُفتح ثقب. على مدونة بحجم 250 مادة ترتفع من 0.35 إلى نحو 0.61
بفوات 5% وإحالة تحكيم دون 1%.

> السكربت **يرفض الكتابة** إن كانت المدونة أصغر من أن تُعاير (دون 150 مادة)،
> لأن العتبة حينها قد تنزل دون الافتراضية فتُضعف الفحص بدل أن تقوّيه.
> وهي خطوة إلزامية في دورة أمين المصادر بعد كل توسيع للمدونة.

## معالجة مستندات القضية

مستندات العميل تصل من خارج المكتب — عقد PDF، خطاب ممسوح، ملف DOCX من الخصم —
فهي **مدخلات غير موثوقة** تُعالَج على هذا الأساس.

```bash
python3 tools/documents/extract_cli.py <المستند> --out cases/<رقم>/mustanadat/<اسم>.md
python3 tools/documents/extract_cli.py --backends    # ما المثبّت وما الناقص
```

**الأمان.** الصيغة تُكشف من محتوى الملف لا من امتداده، فملف خبيث باسم
`عقد.txt` يُعامل بحقيقته. وصيغ Office أرشيفات XML مضغوطة، فتُرفض قنابل الضغط
وانفلات المسار وكيانات XML الخارجية (XXE). ولا يُفتح `.doc` قديم لاحتمال
الماكرو، ولا تُشغَّل أداة خارجية بصدفة أو بلا مهلة أو مع منافذ الشبكة.

**الدقة.** الاستخراج المشوّه أخطر من الفاشل: الفاشل يوقفك، والمشوّه يعطيك نصًا
يبدو سليمًا فتُبنى عليه وقائع. لذلك لكل استخراج **ثقة مقيسة**، وترصد الأداة
أعطاب العربية المعروفة:

| العطب | لماذا يهم |
|---|---|
| حروف مفصولة (`ي ل ت ز م`) | النص غير صالح، والأرقام تتفرّق |
| أشكال العرض بدل الحروف المنطقية | يُطبَّع تلقائيًا، والترتيب قد يبقى معكوسًا |
| ترميز مقروء خطأً | نص لاتيني مشوّه بدل العربية |
| مصدر صورة | التعرّف الضوئي يلتبس في الأرقام والأسماء |

رموز الخروج: `0` سليم · `3` مقبول بتحفظ (قابِل الأرقام بالأصل) · `1` غير صالح ·
`2` تعذّر. **لا يُرجَع نص فارغ بصمت أبدًا** — حين تنقص خلفية تُرفض المعالجة
ويُعرض أمر التثبيت.

### إصدار المخرجات بصيغة Word

المحاكم والعملاء لا يقبلون Markdown. المذكرات والمرافعات والاستشارات تصدر ملفات
`.docx` عربية باتجاه من اليمين:

```bash
python3 tools/documents/export_cli.py مسودة.md --kind memo \
    --out cases/118/مذكرة.docx
```

**البوابة تُشغَّل من داخل الأداة ولا تُتخطى.** التصدير آخر خطوة قبل خروج الوثيقة،
فمسودة مردودة أو معلّقة على تحكيم **لا يُنتج لها ملف Word أصلًا**. وتُزال علامات
الإسناد الآلية، وتُضاف ترويسة المسودة إن كان `output.draft_watermark` مفعّلًا.

الاتجاه العربي مضبوط صراحةً — `w:bidi` على الفقرات، `w:rtl` على التشغيلات،
و`w:szCs` و`w:rFonts w:cs` لمقاس الكتابة المركّبة وخطها. إغفال أيٍّ منها يُنتج
ملفًا يبدو سليمًا ثم يُطبع بمحاذاة يسار وأرقام مقلوبة. والترقيم يُكتب حرفيًا لا
بقوائم Word التلقائية، حتى لا يُعاد ترقيم بنود الطلبات عند التحرير.

الخط والحجم قابلان للضبط بـ`--font` و`--size` (الافتراضي Traditional Arabic، 14).

> ⚠️ الملف مُتحقق منه بنيويًا وبقراءة عكسية، لكنه **لم يُفتح في Word أو
> LibreOffice** أثناء البناء (LibreOffice معطّل في بيئة البناء). افتح أول وثيقة
> تصدرها للتأكد من العرض قبل الاعتماد عليها.

| الصيغة | الخلفية |
|---|---|
| DOCX · ODT · RTF · HTML · نص | المكتبة القياسية — بلا تثبيت |
| PDF | `sudo apt install poppler-utils` |
| صور ومستندات ممسوحة | `sudo apt install tesseract-ocr tesseract-ocr-ara` |

## القوالب الجاهزة

المكتب يخرج أربعة أنواع، لكل نوع قالب ثابت — القالب يوفّر توكنز، ويجعل المراجعة
أسرع، ويمنع نسيان قسم.

| المخرج | القالب |
|---|---|
| مذكرة قانونية | `siyaghat-almudhakkira/references/qalib-mudhakkira.md` |
| مرافعة وصحيفة دعوى | `siyaghat-almurafaa/references/qalib-murafaa.md` |
| **استشارة قانونية** | `siyaghat-alistisharah/references/qalib-istisharah.md` |
| **عقود (6 أنواع)** | `siyaghat-alaqud/references/qalib-*.md` |

### الاستشارة ليست مذكرة
المذكرة تُقنع محكمة في خصومة قائمة؛ الاستشارة تجيب عميلًا ليقرر. فتبدأ بالجواب
لا بالتمهيد، وتعرض الضعف **صراحةً** بدل استباقه، وتنتهي بخيارات لكل منها كلفته
ومخاطره لا بطلبات جازمة.

### العقود: عطب مختلف يحتاج فحصًا مختلفًا
المذكرة تُهزم بإسناد ملفّق. العقد يُهزم بـ**بند ناقص** أو **بند باطل**:

- **الناقص** لا يُرى وقت التوقيع، ويظهر عند النزاع حين لا يجد الطرف ما يحتج به.
- **الباطل** أسوأ: يطمئن العميل إلى حماية لا وجود لها. شرط يُسقط حقًا آمرًا لا
  يصير صحيحًا لأن الطرف الآخر وقّع عليه.

```bash
python3 tools/contracts/check_clauses.py --list           # الأنواع والقوالب
python3 tools/contracts/check_clauses.py عقد.md --type amal
```

ستة قوالب: **عقد عمل · إيجار · بيع · خدمات · اتفاقية عدم إفشاء · اتفاق تسوية**،
كلٌّ منها يجتاز فاحصه الخاص — والقالب الذي لا يجتاز فاحصه يعني أن أحدهما خاطئ.

ولكل بند في `config/clauses.yaml` أساس يحدد كيف يُعامَل:

| الأساس | المعنى | المعاملة |
|---|---|---|
| `structural` | انضباط صياغة لا حكم قانوني (الأطراف، الاختصاص، الإخطارات) | يُفرض مباشرة |
| `statutory` | مبني على نص بحريني | **لا يُفرض إلا بسند يُحل إلى المدونة** |

> ⚠️ حقول `sanad` فارغة عمدًا: أرقام المواد لم يُتحقق منها. فالفاحص يعرض البنود
> القانونية كـ«تحقق يدوي» ويرصدها دون أن يفرضها — لا يفرض المكتب على عقود
> عملائه قاعدة لم يتثبّت أحد من مصدرها.

### ملء الأسناد بعد بناء المدونة

هذه الخطوة تحوّل فاحص العقود من **منبّه** إلى **حاجز**:

```bash
python3 tools/contracts/fill_sanad.py            # مرشّحات لكل بند بلا سند
# اقرأ نص كل مادة واكتب المعتمد في ورقة المراجعة، ثم:
python3 tools/contracts/fill_sanad.py --apply corpus/index/sanad-review.md
python3 tools/contracts/fill_sanad.py --status   # ما المُسنَد وما الناقص
```

الأداة تبحث في المدونة بمصطلحات كل بند (`search_terms`)، وتكتب ورقة تعرض نص كل
مادة مرشّحة. **تقترح ولا تملأ**: مطابقة البحث ليست صحةً قانونية، وأقرب مادة نصًا
قد لا تكون الحاكمة — وهو نفس العطب الذي يعبر بوابة الإسناد لأن رقمه صحيح
ومضمونه لا يسند الحجة.

عند التطبيق **ترفض الأداة أي سند لا يُحل** إلى المدونة، وتكتب في موضعه نصيًا
فتبقى تعليقات الملف كما هي.

| حالة البند | أثره على العقد |
|---|---|
| بلا سند | يُرصد ويُبلَّغ عنه — العقد يمر |
| بسند يُحل | **يُفرض** — العقد يُرفض إن خالفه |

> **ترك الحقل فارغًا أسلم من سند خاطئ.** الأول يُبقي البند تنبيهًا يدويًا،
> والثاني يجعل المكتب يرفض عقود عملائه بناءً على قاعدة لم يتثبّت أحد منها.

الفاحص يرصد أيضًا كل حقل `<…>` وكل بديل `[اختر: … | …]` بقي دون حسم: **حقل غير
مملوء في عقد موقّع فراغ يملؤه الخصم.**

## خط معالجة القضية

```
قيد ← فحص تعارض ← بحث ← تحليل ← صياغة ← تدقيق إسناد ← مراجعة قانونية ← تسليم
                                    ↑__________|__________|
                                     الرد يعيدها للصياغة
```

| المرحلة | المسؤول | النموذج |
|---|---|---|
| القيد | موظف القيد | اقتصادي |
| فحص التعارض | مدقق التعارض | اقتصادي |
| البحث | الباحث القانوني | متوسط |
| التحليل | محلل القضايا | قوي |
| الصياغة | كاتب المذكرات والاستشارات / المرافعات / العقود | قوي |
| تدقيق الإسناد | مدقق الإسناد *(معتمِد)* | متوسط |
| المراجعة | المراجع القانوني *(معتمِد)* | قوي |
| التسليم | الشريك المدير | قوي |

بجانبهم **أمين المصادر** في مساره المعزول.

## التحقق

```bash
./scripts/e2e-test.sh          # 40 فحصًا للنواة الحتمية، بلا شبكة وبلا نموذج
python3 scripts/validate.py    # سلامة الحزمة وتماسك الخط
./scripts/verify-isolation.sh  # العزل والتحصين
```

الاختبار الشامل (40 فحصًا) يثبت الجزء الذي لا يصح أخذه بالثقة — أن التحريف
**يُوقَف فعلًا**:

| الحالة | النتيجة |
|---|---|
| مادة لا وجود لها، تشريع غير مستورد، علامة مشوّهة | رفض |
| قسم قانوني بلا أي إسناد | رفض |
| مقدار مغلوط منسوب لمادة صحيحة الرقم | رفض |
| حكم لا تحمله المادة | إحالة للتحكيم + ورقة مهيكلة |
| مسودة سليمة | قبول وإنتاج الوثيقة النهائية |
| عقد ناقص بندًا إلزاميًا أو فيه حقل غير مملوء | رفض |
| معايرة على مدونة ناقصة | رفض الكتابة |
| محاولة إصدار Word لمسودة مردودة | رفض — لا يُنتج ملف |

رموز خروج البوابة: `0` مقبولة · `1` مردودة · `3` تحتاج تحكيمًا دلاليًا.
ولا تُنتج وثيقة نهائية ما دام هناك بند لم يُحسم.

## تنبيه نظامي

مخرجات المكتب **مسودات**. المرافعة أمام المحاكم البحرينية وممارسة المحاماة مقيدة
نظامًا بالمحامين المقيدين لدى وزارة العدل وفق قانون المحاماة. يُضبط وسم المسودة من
`config/office.yaml` عبر `output.draft_watermark`، ويُنصح بإبقائه مفعّلًا.

المكتب يقدّر ولا يضمن نتيجة قضائية.
