# مكتب استشارات قانوني آلي — مملكة البحرين

مكتب استشارات قانوني يعمل **بلا موظف بشري**، مبني على منصة
[Paperclip](https://github.com/paperclipai/paperclip) مفتوحة المصدر.
يستقبل القضايا ويحللها ويكتب المذكرات والمرافعات وفق القانون البحريني،
بمخرجات تبقى على الجهاز، وبمسار إسناد قابل للتحقق.

**التغطية:** مدني · تجاري · عمالي   **اللغة:** العربية فقط   **المنصة:** Linux

---

## الفكرة في ثلاث نقاط

**1. الاستقرار يأتي من المحرّك لا من التعليمات.**
القضية تسير في خط معالجة بعشر مراحل مع `enforceTransitions`. الانتقالات المسموحة
معرّفة صراحة، فلا يستطيع وكيل تخطي البحث إلى الصياغة، ولا تسليم مسودة لم تمر
بتدقيق الإسناد ثم المراجعة القانونية. مرحلتا المراجعة معتمِدهما **وكيل** لا بشر.

**2. لا إسناد بلا سند.**
كل إشارة قانونية تحمل علامة آلية (`⟦BH:law:36/2012:م111⟧`) تُحل إلى مادة موجودة
فعلًا في مدونة محلية مستوردة من المصادر الرسمية. البوابة **حتمية** — لا نموذج
يحكم عليها — وأي إسناد لا يُحل يعيد المسودة إلى الصياغة تلقائيًا.

**3. العزل مفروض تقنيًا لا موعود به.**
وكلاء القضايا يعملون داخل `bwrap` بمجال شبكي خاص، وقائمة سماحهم لا تحوي إلا واجهة
النموذج. **لا يستطيعون** بلوغ أي موقع. أمين المصادر وحده يبلغ النطاقات الرسمية،
وهو في مشروع منفصل لا يرى أي بيانات قضايا.

---

## ما الذي يبقى محليًا وما الذي لا يبقى

| | |
|---|---|
| ✅ ملفات القضايا والمخرجات وقاعدة البيانات | لا تغادر الجهاز إطلاقًا |
| ✅ التليمتري ومشاركة البيانات وفحص التحديثات | مطفأة ويتحقق منها سكربت |
| ✅ GitHub والتخزين السحابي | غير مفعّلة، ولا رموز وصول |
| ⚠️ **نص القضية أثناء الاستدلال** | **يمر عبر واجهة Anthropic** |

النقطة الأخيرة نتيجة مباشرة لاختيار الاستدلال السحابي، وهي الاستثناء الوحيد.
البنية تسمح بالتحول إلى نموذج محلي بتغيير `adapterConfig` في
`config/agents.yaml` دون إعادة بناء.

## التثبيت

```bash
./scripts/install.sh          # يفحص المتطلبات ويرشدك للخطوات
```

يتطلب: Linux، `bubblewrap`، Python ≥ 3.10 مع PyYAML وsqlite3/FTS5، Node.

ثم بالترتيب:

```bash
# 1) تحصين البيئة والتحقق منه
set -a; . ./config/env.local; set +a      # ضع ANTHROPIC_API_KEY أولًا
./scripts/verify-isolation.sh

# 2) تشغيل Paperclip واستيراد المكتب
npx paperclipai onboard
npx paperclipai company import ./maktab --dry-run
npx paperclipai company import ./maktab --target new \
    --new-company-name "مكتب الاستشارات القانونية" --yes
./scripts/verify-isolation.sh             # onboard يعيد تفعيل التليمتري — أعد الفحص

# 3) تهيئة الخط والعزل والسقوف
export PAPERCLIP_API_URL=http://127.0.0.1:3100
export PAPERCLIP_API_KEY=<token>
python3 scripts/provision.py --company-id <uuid>

# 4) بناء المدونة القانونية — المكتب لا يعمل بدونها
python3 tools/ingest/ingest.py --from-staging
python3 tools/corpus/corpus_cli.py stats
```

> `paperclipai company import` يأخذ المسار **موضعيًا** لا بـ`--from`،
> خلافًا لما في توثيق Paperclip.

## بناء المدونة القانونية

هذه أهم خطوة: **المكتب لا يستطيع إصدار أي إسناد قبلها**، والاستيراد يُشغَّل على
جهازك لأن النصوص تأتي من المصادر البحرينية الرسمية.

```bash
# نزّل النص الرسمي لكل تشريع إلى مجلد التجهيز
#   corpus/staging/labour-private-sector.html
#   corpus/staging/civil-code.html          ... إلخ
python3 tools/ingest/ingest.py --from-staging
```

الاستيراد **يتحقق من العنوان** بمقارنة النص المُنزَّل بالمُعلن في
`corpus/sources.yaml`، ولا يوسم التشريع `verified` إلا بعد المطابقة. والوكلاء لا
يستطيعون الاستشهاد بغير المُتحقق منه.

> ⚠️ أرقام التشريعات وسنواتها في `corpus/sources.yaml` **مرشّحات للتحقق لا حقائق
> مثبتة** — لم يُتحقق منها آليًا لأن بيئة البناء تحجب النطاقات البحرينية. عند
> تعارض العنوان **صحّح السجل ليطابق النص الرسمي، لا العكس**.
> ولا يحوي هذا المستودع أي نص قانوني مكتوب يدويًا، عمدًا.

مصادر PDF تُحوَّل أولًا:
```bash
pdftotext -enc UTF-8 -layout ملف.pdf corpus/staging/<key>.txt
```

## خط معالجة القضية

```
قيد ← فحص تعارض ← بحث ← تحليل ← صياغة ← تدقيق إسناد ← مراجعة قانونية ← تسليم
                                    ↑__________|__________|
                                     الرد يعيدها للصياغة
```

| المرحلة | المسؤول | النموذج |
|---|---|---|
| القيد | موظف القيد | اقتصادي |
| فحص التعارض | مدقق التعارض | اقتصادي |
| البحث | الباحث القانوني | متوسط |
| التحليل | محلل القضايا | قوي |
| الصياغة | كاتب المذكرات / المرافعات | قوي |
| تدقيق الإسناد | مدقق الإسناد *(معتمِد)* | متوسط |
| المراجعة | المراجع القانوني *(معتمِد)* | قوي |
| التسليم | الشريك المدير | قوي |

بجانبهم **أمين المصادر** في مساره المعزول.

## خفض التوكنز

| الرافعة | أين تُضبط |
|---|---|
| توجيه النماذج حسب الدور — اقتصادي للأدوار الميكانيكية | `maktab/.paperclip.yaml` |
| قصر المهارات المركّبة على المعلن، ونزع حزمة الـCEO الافتراضية (~95KB) | `config/agents.yaml` |
| إلغاء النبضات الفارغة (`skipTimerWhenNoActionableWork`) | `config/agents.yaml` |
| سقوف يومية للتشغيل والتكلفة (غير متاحة في الواجهة) | `config/agents.yaml` |
| خفض التزامن من 20 إلى 2 | `config/agents.yaml` |
| إيقاف الاستئناف التلقائي بعد استنفاد الأدوار | `config/agents.yaml` |
| خفض سقف الأدوار من 1000 إلى 12–60 حسب الدور | `config/agents.yaml` |
| استرجاع مقاطع المواد بدل تحميل القوانين كاملة | `tools/corpus` |
| تعليمات مرحلية وحقول مهيكلة بدل نثر منقول | `pipelines/qadiya.stages.json` |
| قوالب حتمية — النموذج يكتب التسبيب فقط | `maktab/skills/*/references/` |

```bash
python3 scripts/measure-tokens.py --company-id <uuid> --save baseline.json
# ... بعد التعديلات
python3 scripts/measure-tokens.py --company-id <uuid> --baseline baseline.json
```

## التحقق

```bash
./scripts/e2e-test.sh          # 14 فحصًا للنواة الحتمية، بلا شبكة وبلا نموذج
python3 scripts/validate.py    # سلامة الحزمة وتماسك الخط
./scripts/verify-isolation.sh  # العزل والتحصين
```

الاختبار الشامل يثبت الجزء الذي لا يصح أخذه بالثقة: أن الإسناد الملفّق **يُوقَف
فعلًا** — مادة لا وجود لها، وتشريع غير مستورد، وعلامة مشوّهة، وقسم قانوني بلا سند.


## تنبيه نظامي

مخرجات المكتب **مسودات**. المرافعة أمام المحاكم البحرينية وممارسة المحاماة مقيدة
نظامًا بالمحامين المقيدين لدى وزارة العدل وفق قانون المحاماة. يُضبط وسم المسودة من
`config/office.yaml` عبر `output.draft_watermark`، ويُنصح بإبقائه مفعّلًا.

المكتب يقدّر ولا يضمن نتيجة قضائية.
