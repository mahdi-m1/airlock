# مكتب الاستشارات القانونية — حزمة الشركة

حزمة `agentcompanies/v1` لمكتب استشارات قانوني بحريني يعمل بلا موظف بشري.

## المحتوى

- **10 وكلاء** موزّعين على 5 فرق: الاستقبال والقيد · البحث والتحليل · الصياغة ·
  المراجعة والامتثال · المصادر.
- **10 مهارات** بصيغة Agent Skills، تفاصيلها في `references/` تُحمَّل عند الحاجة.
- **مشروع ومهمة دورية** لصيانة المدونة القانونية.

## الاستيراد

```bash
paperclipai company import ./maktab --dry-run
paperclipai company import ./maktab --target new \
    --new-company-name "مكتب الاستشارات القانونية" --yes
```

## ما لا تحمله هذه الحزمة

الحزمة وحدها **لا تكفي**. مواصفة `agentcompanies/v1` لا تحمل خطوط المعالجة ولا
سياسات المراجعة ولا عزل الشبكة، والمستورد يعطّل مؤقتات التشغيل ويوقف الأتمتة.
لذلك يجب بعد الاستيراد:

```bash
python3 scripts/provision.py --company-id <uuid>
```

وهو ما يُنشئ خط `qadiya` بمراحله وانتقالاته المفروضة، ويضبط عزل الشبكة والسقوف
اليومية لكل وكيل، ويستأنف الأتمتة.

ثم تُبنى المدونة القانونية قبل أول قضية — انظر `README.md` في جذر المستودع.
