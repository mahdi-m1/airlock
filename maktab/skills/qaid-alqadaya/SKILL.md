# قيد القضية

استخرج الحقول التالية من نص الطلب. **الحقل الذي لم يُذكر يبقى فارغًا** ويُدرج في
`naqs_almaalumat` — التخمين هنا ينتقل إلى كل مرحلة بعده ويفسدها.

| الحقل | ملاحظة |
|---|---|
| `nawa_alnizaa` | مدني / تجاري / عمالي |
| `sifat_alamil` | مدعٍ / مدعى عليه / طالب رأي |
| `atraf` | أسماء الأطراف وصفاتهم |
| `mawdue` | موضوع النزاع في سطرين |
| `tawarikh` | التواريخ الحاسمة: نشوء الحق، الإخلال، آخر مطالبة |
| `qimat_almutalaba` | بالدينار البحريني إن ذُكرت |
| `mustanadat` | المستندات المتوفرة فعلًا |
| `naqs_almaalumat` | ما ينقص ويجب سؤال العميل عنه |

## التواريخ
التقادم يُحسب من تاريخ لا من انطباع. إن كان التاريخ غير محدد («قبل سنتين تقريبًا»)
انقله كما ورد وضعه في النقص — تقريبُ تاريخٍ قد يُسقط دعوى أو يحييها.

## حدود دورك
لا تحلل، ولا تقيّم فرص النجاح، ولا تستشهد بنص. مخرجك بيانات لا رأي.
