# معالجة المستندات

```
python3 tools/documents/extract_cli.py <المستند> --out cases/<رقم>/mustanadat/<اسم>.md
python3 tools/documents/extract_cli.py --backends     # ما المثبّت وما الناقص
```

## رمز الخروج يحكم

| الرمز | المعنى | إجراؤك |
|---|---|---|
| `0` | استخراج سليم | انقل الوقائع منه |
| `3` | مقبول بتحفظات | **قابِل كل تاريخ ومبلغ واسم بالأصل** قبل النقل |
| `1` | غير صالح | لا تبنِ عليه واقعة. اطلب نسخة أوضح |
| `2` | تعذّر (أداة ناقصة أو صيغة مرفوضة) | اتبع الإرشاد المعروض |

## القاعدة

**الاستخراج المشوّه أخطر من الفاشل.** الفاشل يوقفك؛ والمشوّه يعطيك نصًا يبدو
سليمًا فتُبنى عليه وقائع. تاريخ أو مبلغ مقروء خطأً من عقد يفسد القضية كما يفسدها
إسناد ملفّق تمامًا — والفرق أن هذا لا تلتقطه بوابة الإسناد لأنه ليس إسنادًا.

فإذا قالت الأداة «مقبول بتحفظات» فالتحفظ ليس شكليًا: افتح المستند الأصلي وقابِل
الأرقام حرفًا حرفًا.

## ما يعمل بلا تثبيت
DOCX · ODT · RTF · HTML · نص — بالمكتبة القياسية.

## ما يحتاج أداة
- **PDF**: `sudo apt install poppler-utils`
- **صور ومستندات ممسوحة**: `sudo apt install tesseract-ocr tesseract-ocr-ara`

الأداة **ترفض صراحةً** ولا تُرجع نصًا فارغًا حين تنقص الخلفية.

## ما لا يُفتح
- **`.doc`/`.xls` القديمة** — قد تحوي ماكرو. تُحوَّل في بيئة معزولة أولًا:
  `soffice --headless --safe-mode --convert-to docx <الملف>`
- **الأرشيفات المضغوطة** — تُفك ويُمرَّر كل مستند على حدة.
- أي ملف بمسار خطر داخله أو نسبة ضغط شاذة أو كيانات XML — يُرفض تلقائيًا.
